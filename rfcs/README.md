# RFCs

**Classification:** Engineering  
**Status:** Planned  
**Related Glossary:** [GLOSSARY.md](../GLOSSARY.md)

本目录用于记录 BUP 的规范性设计。RFC 应建立在 Research Notes 和案例证据之上，不得反向定义尚未稳定的 ABU 理论。

## RFC 路线

| RFC | 名称 | 依赖 | 当前状态 |
|---|---|---|---|
| RFC-0000 | BUP RFC Writing Convention | 项目治理规则 | Planned |
| RFC-0001 | ABU Definition and Conceptual Model | RN-0001、RN-0004 | Planned |
| RFC-0002 | BUP Specification | RFC-0001、OQ-0004 | Planned |
| RFC-0003 | BUSINESS.md Authoring Guide | RFC-0002、游戏案例 | Planned |
| RFC-0004 | Reference Cases | 游戏案例试验 | Planned |
| RFC-0005 | Evaluation Benchmark | 实验预注册、游戏试验 | Planned |

## 生命周期

```text
Draft
  → Research Review
  → Game Pilot
  → Revised Draft
  → Cross-domain Validation
  → Accepted
```

RFC-0002 至 RFC-0005 不应在游戏试验前标记为 Accepted。

## 最低结构

1. Abstract；
2. Motivation；
3. Problem Statement；
4. Design Goals；
5. Non-goals；
6. Design Rationale；
7. Specification；
8. Running Example；
9. Alternatives Considered；
10. Open Questions；
11. Future Work。
