# Scoring Rubric

**Classification:** Research / Engineering  
**Status:** Skeleton — Not Preregistered  
**Version:** 0.0  
**Related Glossary:** [GLOSSARY.md](../GLOSSARY.md)

> 本文件目前只定义待操作化的评价维度，不包含最终评分锚点。

## Planned Dimensions

| 维度 | 待操作化的问题 |
|---|---|
| 假设质量 | 如何区分相关性、可验证性、优先级和覆盖度？ |
| 根因命中程度 | 是按预设答案匹配，还是允许证据支持的替代解释？ |
| 分析路径合理性 | 如何评价检查顺序、条件依赖和证据选择？ |
| 无效排查数量 | 什么算独立排查，什么算必要的排除步骤？ |
| 业务一致性 | 如何识别与已知业务规律冲突的论断？ |
| 证据引用质量 | 如何评价证据相关性、准确性和充分性？ |
| 搜索空间缩小 | 用候选假设数量、路径长度还是信息增益衡量？ |
| 表示适配性 | 是否能识别 Transition 不适合的问题，并正确引用替代视图？ |
| 未知机制开放性 | BUSINESS.md 未覆盖的解释能否在 Evidence 支持下被提出？ |
| 错误模型恢复 | ABU 缺失、过期或错误时，是否能识别冲突并修正分析？ |

## Required Before Use

- 为每个维度写出可观察定义；
- 选择评分尺度并给出每一级锚点；
- 提供至少一个正例、边界例和反例；
- 规定维度权重和主要结果；
- 规定评分者分歧处理；
- 用不进入正式 Benchmark 的样例完成校准；
- 通过 Decision Record 冻结版本。
