# G0-A005

## Current diagnosis

按时完成率下降可能同时来自技术员负载、故障变复杂和备件目录变化，需要逐项排查。

## Ranked hypotheses

1. 技术员排班不足造成积压；
2. 最近的压缩机故障更严重，现场处理更久；
3. 目录重编码遗漏兼容映射，导致可用备件被扫描拒绝；
4. 路线规划使技术员更晚到场。

## Next checks

1. 检查技术员人数、排班和人均工单量是否变化；
2. 比较故障严重度和故障码构成；
3. 按目录版本、设备型号和仓库比较 `part_scan_rejected`；
4. 抽样核对被拒部件的实物库存与新旧兼容映射；
5. 在一个仓库回滚目录或补齐映射，观察人工放行等待与 SLA 是否恢复。

## Uncertainty and model limits

目录问题值得关注，但现场处理时间上升也可能说明故障变难。目前没有足够证据确定哪一个最重要。

## Conclusion

先从技术员负载开始，再逐步检查故障和目录问题，置信度中等。
